## OPVF
OPVF - методика оценки потенциала возвращения образовательной функции зданиям советских учреждений
Работа направлена на формирование нового подхода к оценке нефункционирующих исторических зданий рассматриваемого периода.

## Основные возможности
Четырёхкомпонентная модель оценки: поддержка четырёх категорий критериев — архитектурно-планировочные (K1), социально-экономические (K2), инженерно-технические (K3), историко-культурные (K4).

Бинарная оценка критериев: автоматическое сравнение исходных данных с нормативными требованиями (1 — соответствует норме, 0 — не соответствует).

Расчёт интегрального показателя I: агрегация средних баллов по четырём категориям в итоговую оценку от 0 до 4.

Интерпретация результатов: автоматическое определение уровня потенциала (высокий / средний / ограниченный / низкий) и формирование рекомендаций по типу работ.

Импорт данных: загрузка из Excel (.xlsx) и CSV с предустановленными шаблонами критериев.

Экспорт отчётов: сохранение детальных результатов оценки в Excel с графиками и диаграммами.

Визуализация: построение круговых диаграмм по четырём категориям с цветовым кодированием (зелёный — высокий потенциал, красный — низкий).

## Критерии оценки
### Архитектурно-планировочные
Оптимальный размер земельного участка, оптимальная площадь открытых площадок, оптимальная площадь зоны отдыха на участке, оптимальная площадь хозяйственной зоны на участке, соответствие объемно-планировочной структуры типологии школы, необходимая площадь здания, наличие зальных помещений, современное функциональное использование, возможность строительства зданий на участке.
# Социально-экономические
Качество окружающего воздуха, акустический комфорт, естественное освещение, озелененная территория участка, соответствующая функциональная зона территории, транспортная доступность, настоящая необходимость в образовательном учреждении, возможная необходимость в образовательном учреждении.
# Инженерно-техническкие
Возможность устройства пожарного проезда, класс конструктивной пожарной опасности здания, расстояние от границ земельного участка до других объектов, инженерное оборудование здания, прочность и надежность конструкций, сохранность исторической части здания.
# Историко-культурные
Датировка, мемориальность, подлинность, представительность, градостроительная ценность, ансамблевость, конструктивно-технологическая ценность, архитектурно-художественная ценность интерьеров, научно-познавательная ценность, учебно-педагогическая ценность, художественно-эстетическая ценность, публичная и общественная значимость, социокультурная ценность, распространeнность, оптимальные режимы использования земель, этапность, видимость.


## Результат работы

Интегральный показатель I (0–4) для каждого объекта.

Уровень потенциала: высокий, средний, ограниченный, низкий.

Рекомендации по типу работ.

Визуализацию в виде круговой диаграммы с цветовой индикацией по четырём категориям.

## Требования к исходным данным

Для проведения оценки необходимо подготовить файл с исходными данными (Excel или CSV) в соответствии со следующей структурой:

| № | Данные | Тип | Требование к данным |
|---|--------|-----|---------------------|
| 1 | Наименование объекта | string | Сначала указывается историческое наименование здания образовательного учреждения, через запятую — современное. При отсутствии исторического наименования приводится современное |
| 2 | Адрес | string | Адрес в формате: город, улица, дом |
| 3 | Функциональная зона территории | string | Функциональная зона в соответствии с генеральным планом Санкт-Петербурга |
| 4 | Режим использования земель | string | Режим использования земель в соответствии с зонами охраны Санкт-Петербурга |
| 5 | Размер земельного участка (Sзу) | float | Площадь современного участка в м² |
| 6 | Площадь здания (Sзд) | float | Сумма поэтажных площадей современного здания в м² |
| 7 | Площадь застройки (Sз) | float | Площадь, занимаемая основным строением, в м² |
| 8 | Площадь озеленения участка (Sо) | float | Площадь зелёных насаждений на участке в м² |
| 9 | Год ввода в эксплуатацию | int | Год ввода здания в эксплуатацию; при отсутствии данных — год окончания строительства |
| 10 | Год прекращения функции образовательной организации | int | Год, когда образовательная функция в здании была изменена на иную |
| 11 | Новая функция | string | Последняя функция, существовавшая в здании, либо её отсутствие |
| 12 | Проектная вместимость здания (W) | int | Количество обучающихся по первоначальному проекту (в местах) |
| 13 | Тип проекта | string | Номер типового проекта, либо индивидуальный проект, фамилия архитектора |
| 14 | Архитектурный стиль | string | Стиль, в котором изначально построено здание |
| 15 | Наличие исторической отделки | boolean | Информация об исторической отделке интерьеров, соответствующей стилю |
| 16 | Историческое здание | boolean | Информация о включении в реестр объектов культурного наследия Санкт-Петербурга |
| 17 | Техническое состояние здания | string | Состояние здания по визуальному осмотру: исправное, работоспособное, ограниченно работоспособное, аварийное |
| 18 | Материал наружных стен, перекрытий, кровли | string | Основной материал наружных стен, перекрытий, кровли (через запятую) |
| 19 | Подключение к городским коммуникациям | boolean | Информация о подключении к городским коммуникациям |

### Структура

| Папка | Описание |
|--------|----------|
| `data` | Данные из Excel и CSV |
| `examples` | Пример применения методики |
| `method` | Методические рекомендации, оформленные в формате pdf |
| `tests` | Применение методики на тестовых кейсых |
